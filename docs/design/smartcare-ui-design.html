SmartCare User Account, final UI design

A fresher take on the same screens. Each login screen has a blue gradient header with a white sheet that slides up over it. Patient screens use bright medical blue and staff screens use navy, so it's always clear which side of the app you're on.

Design notes

  • Sheet layout: each login screen has a blue gradient header, and the form sits on a white sheet that overlaps it.
  • Two shades: Clinic Sky blue for patients, navy for staff.
  • Floating labels: the field name sits inside the box, so the form is shorter.
  • Two-step sign up: personal details first, then email and password. Date of birth and gender show as "From IC" cards.
  • Home: a large next-appointment card with the check-in code, a chatbot shortcut, and a floating tab bar.
  • For Android: every element here can be built with standard Material components (TextInputLayout, MaterialButton, BottomSheet-style CardView).
